# Data Pipeline

## Big flow

```text
workflow trigger
  -> checkout repo
  -> checkout subtitles repo
  -> install deps + FFmpeg
  -> run scrape
  -> update generated JSON/SRT artifacts
  -> commit changes
  -> send Matrix message
```

## Step by step

### 1. Trigger

`.github/workflows/update.yaml` runs on:

- push to `main`
- hourly cron: `0 * * * *`
- manual dispatch

### 2. Load source data

`scripts/scrape.ts` starts by calling `fetchArcs()` from `scripts/sheets.ts`.

`fetchArcs()` does this:

1. load arc list from Google Sheets
2. load per-arc episode rows
3. load metadata sheet for better titles/descriptions
4. resolve each Nyaa link into:
   - `infoHash`
   - `.torrent` download URL
   - CRC32 marker from sheet cell text

Nyaa lookups cached in `cache/nyaa.json`.

## 3. Build One Pace videos and streams

For each sheet episode, `scrape.ts` calls `getVideo()` in `scripts/parse.ts`.

`getVideo()` does this:

1. build stable `Video` object
2. fetch cached or remote `.torrent`
3. parse torrent file list
4. find file ending with `[CRC32].mkv`
5. if match found, create `Stream`
6. attach subtitles from `getSubtitles()` when available

If no torrent file match found, metadata still exist, but stream may be absent.

## 4. Track covered anime episodes

When stream exists, `scrape.ts` parses `episode.animeEpisodes` and marks covered anime ranges.

This coverage map decides where KAI fallback must fill holes.

## 5. Fill holes with One Piece Kai

`scripts/kai.json` holds KAI fallback data.

For each KAI entry:

- parse its covered anime episodes
- skip if all already covered by One Pace streams
- find matching arc by title
- append new synthetic episode number at end of that arc season
- create stream with shared KAI `infoHash` and per-entry `fileIdx`

This means KAI acts as gap filler, not primary source.

## 6. Remove stale output

Before final write, `scrape.ts` compares new videos against old `meta/series/onepace.json`.

Removed leftovers cause old `stream/series/<id>.json` files to be deleted.

`utils.ts` also removes subtitle files when subtitle languages disappear.

## 7. Write artifacts

Main outputs:

- `meta/series/onepace.json`
- `stream/series/<id>.json`
- `static/<id>_<lang>.srt`

`catalog/series/seriesCatalog.json` and `manifest.json` are static repo files, not regenerated by `scrape.ts` in current code.

## Invariants maintainers should protect

- Every arc title from sheets must exist in `scripts/arcs.json`.
- Episode ID format must stay stable.
- KAI arc names must match sheet arc names.
- Subtitle filename matching depends on exact arc title + zero-padded episode number.
- External sources can fail: Google Sheets, Nyaa, subtitle checkout, FFmpeg.

## Current-state gap

Pipeline writes torrent-backed Stremio stream payloads.

No debrid-provider transformation step found in current code.
